# Code of conduct

Be respectful. No harassment, hate, or personal attacks.

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) in spirit: assume good intent, disagree on the code, and leave the person alone.

Report problems to the maintainer: [Gromsi](https://github.com/Gromsi) (repo owner).
